# Agent adoption snippet dogfood summary

## Setup

- Temp repo: `/tmp/hk-agent-adoption-trial/repo`
- Agent: `codex exec`
- Prompt did **not** mention HK or AGENTS.md.
- `AGENTS.md` contained only the snippet generated by `scripts/hk-dev instructions --scope user`.
- `hk` was made available through a PATH wrapper that logged every invocation and delegated to `scripts/hk-dev`.

## Result

The agent followed the user-level snippet without being explicitly told to use HK.

Observed HK behavior:

- Ran `hk profile resolve --target . --json` at the start.
- Read additional HK guidance with `hk instructions --profile generic --json` and later `hk instructions --profile python --json`.
- Listed profiles and ran `hk brief`.
- Tried `hk start ... --profile python --profiles-dir ...`, which failed because `hk start` does not accept profile flags.
- Recovered by running `hk start ... --target . --json` successfully.
- Ran native validation through `hk validate --why` for pytest, ruff lint, ruff format, and ty.
- Captured a failed `ty` validation, corrected the native command by adding `pytest`, and captured the passing rerun.
- Ran `hk status`, `hk decide --spec-impact not-needed`, `hk review prompt`, `hk dangerously-skip review`, `hk sync`, `hk ready`, and `hk handoff`.
- Did not commit changes.

## Metrics

- HK completed commands: 21
- Failed HK commands: 2
  - `hk start ... --profile python --profiles-dir ...` failed because `start` does not accept profile flags.
  - `hk validate ... uv run --with ty ty check` failed because pytest was missing from the temporary tool environment.
- Final `hk ready`: passed.
- Final `hk handoff`: rendered successfully.

## Findings

1. The compact AGENTS snippet is enough for a fresh Codex agent to start with HK.
2. The agent did more than the snippet required: it discovered checks, recorded decisions, handled review, synced, checked readiness, and rendered handoff.
3. The main UX sharp edge is profile-flag propagation: after seeing profile-related commands, the agent tried to pass `--profile` and `--profiles-dir` to `hk start`, where those flags are invalid.
4. The review requirement was understood, but the agent chose `dangerously-skip review` because no independent reviewer was available in the session.

## Follow-ups to consider

- Improve `hk start` error/help when agents pass profile flags, possibly by saying profile selection belongs to `hk checks`/`hk instructions --scope repo`, not `start`.
- Consider whether `hk status` should suggest the exact review-skip wording when no fresh reviewer is available.
- Keep the user-level snippet short; it performed well in this trial.
