# SPEC — hk2-docs-ux-followups

## Goal

Apply a small documentation pass based on user feedback after the session-artifacts skill work.

## Requirements

- Do not add an HK1 migration guide; HK1 was a prototype and can be reset.
- Frame HK2 as primarily agent-facing lifecycle and handoff tooling, not a human task manager.
- Add a lightweight advanced/agent command index so the rest of the CLI surface is discoverable without becoming the promoted path.
- Capture follow-up ideas as future work, not launch blockers.
- Keep examples and review UX guidance light.

## Non-goals

- No source behavior changes.
- No new command surfaces.
- No expanded migration documentation.
